    Here's the build order:

**Phase 1 -- Core Backend**
1. Database schema (tables: schools, students, exam_configs, results)
2. `scorer.py` -- compare detected answers to answer key, compute skill scores
3. `reporter.py` -- generate PDF report card with radar chart
4. `main.py` -- ties OMR pipeline together (align → read → score → store in DB)
5. FastAPI endpoints -- upload, process, fetch results

**Phase 2 -- Frontend**
6. Admin dashboard -- upload OMRs, select/create exam config, view batch status
7. Student search -- look up any student, view their results
8. Batch results view -- summary table, average scores per skill
9. PDF viewer -- inline PDF generation on demand

**Phase 3 -- Polish**
10. ZIP upload support
11. Storage indicator
12. Manual delete for old batches
13. User guide
